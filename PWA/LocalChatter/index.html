LocalChatter

Messages appear here while you're connected. Nothing is saved: when you leave, they're gone.

Everyone in the chat sees it. You can also type /fire, /earthquake, /lightning or /zalgo 30 (seconds; /zalgo on until /zalgo off).

Soundboard

No sounds yet. Tap Manage sounds to add some.

Games

Wall: knock it down by sending messages. Hangman: everyone's messages are guesses (their first letter). Drop Race: everyone's next message drops through the pins; first to the bottom wins.

Polls

Ask everyone a question. Results show on the displays as votes come in. Type /poll to see the running polls.

Favourites

    Tap ☆ next to an effect in the chat to keep it here.

    Open the LocalChatter server's page on this device (for example https://192.168.1.50:8443) and tap Set up LocalChatter, or type its address here.

    Can't connect? Open the server page and accept its certificate, then try again.

    Languages

    Changes here apply straight away. Messages in languages you don't understand look like gibberish; join and leave lines are in System. You can also use /languages and /speak.
