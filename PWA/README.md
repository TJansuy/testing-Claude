# PWA

Exploration of Progressive Web Apps.

| Folder | Description |
| --- | --- |
| [Sample](Sample/index.html) | Minimal Hello World PWA that runs without a server. |
| [LocalChatter](LocalChatter/) | Local-network chat room (messages, images, files) with a containerised relay server. No history. |
| [Rally](Rally/) | Tennis for two, device to device on the same Wi-Fi (no server): real ball physics in WebAssembly, drawn with WebGL. |
